# claude-code-facts

Machine-readable facts about Claude Code. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `ai-agent-facts` under the sub-path `ai-agent-facts/claude-code`, for example `readFacts('ai-agent-facts/claude-code')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the owners of Claude Code. Product names are trademarks of their respective owners.
