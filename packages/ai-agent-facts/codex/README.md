# codex-facts

Machine-readable facts about Codex. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `ai-agent-facts` under the sub-path `ai-agent-facts/codex`, for example `readFacts('ai-agent-facts/codex')`.
