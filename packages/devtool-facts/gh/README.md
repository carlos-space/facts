# gh-facts

Machine-readable facts about the GitHub CLI (gh). Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `devtool-facts` under the sub-path `devtool-facts/gh`, for example `readFacts('devtool-facts/gh')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the owners of the GitHub CLI (gh). Product names are trademarks of their respective owners.
