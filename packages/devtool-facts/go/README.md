# go-facts

Machine-readable facts about the Go toolchain (go). Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `devtool-facts` under the sub-path `devtool-facts/go`, for example `readFacts('devtool-facts/go')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the Go project or Google. Product names are trademarks of their respective owners.
