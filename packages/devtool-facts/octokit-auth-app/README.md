# octokit-auth-app-facts

Machine-readable facts about @octokit/auth-app (octokit-auth-app), the GitHub App authentication strategy for Octokit. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `devtool-facts` under the sub-path `devtool-facts/octokit-auth-app`, for example `readFacts('devtool-facts/octokit-auth-app')`.
