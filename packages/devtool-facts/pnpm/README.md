# pnpm-facts

Machine-readable facts about pnpm. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `devtool-facts` under the sub-path `devtool-facts/pnpm`, for example `readFacts('devtool-facts/pnpm')`.
