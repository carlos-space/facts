# release-please-facts

Machine-readable facts about release-please. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `devtool-facts` under the sub-path `devtool-facts/release-please`, for example `readFacts('devtool-facts/release-please')`.
