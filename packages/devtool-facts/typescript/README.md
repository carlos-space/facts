# typescript-facts

Machine-readable facts about TypeScript. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `devtool-facts` under the sub-path `devtool-facts/typescript`, for example `readFacts('devtool-facts/typescript')`.
