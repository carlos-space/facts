# wrangler-facts

Machine-readable facts about Cloudflare Wrangler (wrangler). Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `devtool-facts` under the sub-path `devtool-facts/wrangler`, for example `readFacts('devtool-facts/wrangler')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the owners of Cloudflare Wrangler (wrangler). Product names are trademarks of their respective owners.
