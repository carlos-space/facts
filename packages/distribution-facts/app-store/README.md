# app-store-facts

Machine-readable facts about Apple App Store. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `distribution-facts` under the sub-path `distribution-facts/app-store`, for example `readFacts('distribution-facts/app-store')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the owners of Apple App Store. Product names are trademarks of their respective owners.
