# apple-notarization-facts

Machine-readable facts about Apple notarization, code signing and Gatekeeper. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `distribution-facts` under the sub-path `distribution-facts/apple-notarization`, for example `readFacts('distribution-facts/apple-notarization')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the owners of Apple notarization, code signing and Gatekeeper. Product names are trademarks of their respective owners.
