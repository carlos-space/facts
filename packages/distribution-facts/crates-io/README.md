# crates-io-facts

Machine-readable facts about crates.io. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `distribution-facts` under the sub-path `distribution-facts/crates-io`, for example `readFacts('distribution-facts/crates-io')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the owners of crates.io. Product names are trademarks of their respective owners.
