# npm-facts

Machine-readable facts about npm. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `distribution-facts` under the sub-path `distribution-facts/npm`, for example `readFacts('distribution-facts/npm')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the owners of npm. Product names are trademarks of their respective owners.
