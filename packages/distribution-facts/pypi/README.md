# pypi-facts

Machine-readable facts about PyPI. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `distribution-facts` under the sub-path `distribution-facts/pypi`, for example `readFacts('distribution-facts/pypi')`.

This package is unofficial. It is not affiliated with, endorsed by, or sponsored by the owners of PyPI. Product names are trademarks of their respective owners.
