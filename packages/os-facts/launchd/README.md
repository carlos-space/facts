# launchd-facts

Machine-readable facts about launchd (launchd), the macOS service manager. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `os-facts` under the sub-path `os-facts/launchd`, for example `readFacts('os-facts/launchd')`.
