# github-actions-facts

Machine-readable facts about GitHub Actions. Each fact records where it came from and, for observed facts, how to check it again.

This is a private workspace package and is not published. Its facts ship in `service-facts` under the sub-path `service-facts/github-actions`, for example `readFacts('service-facts/github-actions')`.
